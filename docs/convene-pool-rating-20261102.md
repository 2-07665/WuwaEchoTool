# 限定池独立称号试版

总览首张主卡保留整体运势和整体分享。下方普通限定角色池（1）、限定武器池（2）各自展示徽章、八阶称号、分数、样本数量、计分分项及权重，再接抽取统计与保底进度。其他卡池仍保留原折叠入口，不新增称号。个人角色取得称号保持原规则。

`ConveneCore.poolLuck(stats, pool)` 仅接受池 1、2。有效间隔只取本池非异常、非未知的五星间隔，样本和抽数门槛均不能借用另一池或常驻池。角色池沿用原速度／小保合成规则及可信度门槛；武器池仅使用速度分数，取消小保覆盖与机会门槛。两池只要有可计算分数便直接显示对应称号，包括零分；不展示暂定、正式授予或样本不足等状态。样本数和抽数仅作参考，不展示达标分母。没有有效间隔、无法计算分数时仍显示待观测。内部样本证据字段保留，整体运势原门槛不变。

本次没有修改游戏规则或官方数据，新增部分属于工具展示与评级政策。存档版本不变，不写回派生评级，旧存档按现有记录即时重算。繁简英沿用现有翻译表。

各限定池增加独立分享入口，使用 `ConveneShare.renderPool` 绘制 1200px PNG。简略版展示本池评级与六项统计，详细版增加本池有效间隔分布和规则。两版均只读取指定池，默认隐藏 UID，下载与预览复用同一 PNG。无可计算分数时入口禁用，样本不足但有分数时直接分享对应称号。

限定池新增专用八阶外框和徽章，角色池为弧形声波／双星，武器池为剑脊／锻造刻线。角饰、侧边刻纹、顶饰和高阶光边均由各池实际称号控制，不依赖整体阶级；待观测保持简洁基础外框。`poolFrameArtwork` 同时供页面 SVG 和分享 Canvas 使用，桌面与手机有独立 SVG 比例；无持续动画。八阶与待观测的两池对照见 `pool-frame-tiers.png`。

验证：`node --test tests/*.test.cjs` 共 291 项通过；`node tests/convene-pool-rating-browser.cjs` 检查 1440、390、360 三种宽度与三种语言，验证无横向溢出、独立卡池分析、整体主卡及分享可用、两池独立简略／详细 PNG 下载与预览一致及原存档不变。合成示例截图位于 `artifacts/convene-pool-rating-20261102/`，不代表真实账号。

称号徽章细化：低阶采用中央晶体与基础印记，二阶增加外环，三阶展开侧翼及底饰，四阶增加第二层翼片和冠座，五阶追加绶带／晶核，六阶展开冠饰，七阶增加外轨与侧晶，八阶追加星芒。两池分别使用流线与硬边轮廓，保留双星／剑脊识别核心；页面和分享仍由同一 `artwork` 路径绘制。此次定向测试 13 项及 9 组三语／视口浏览器检查通过。
