# 共鸣成就扩充与图示语义规则

2026-11-02：原有 26 项保留，先补充 8 项，再增加 4 项传说与 4 项神话，共 42 项。稀有度从低到高为普通、稀有、史诗、传说、神话；数量分别为 4、11、11、12、4。

## 图示规则

- 中心图案按稳定成就键明确映射，不再按索引循环分配，不根据稀有度选择主题。
- 仅相关进阶使用同一主题：抽数为远航、五星累计为宝藏、角色为旅伴、武器为兵器、月份为时间、小保胜利为王冠或守护盾。每项仍有独立中心图案。
- 普通为素面框，稀有为盾框，史诗为翼章，传说为桂冠框，神话为独立放射星环与白金虹彩。神话 SVG 与 Canvas 共用同一组六段渐变色。外框及金属色只表达本工具设定的解锁难度，不代表全服解锁率或成就内容。
- 页面 SVG、总览缩略图和分享 Canvas 共用 achievementArtwork 路径，未解锁继续使用原状态显示。
- 预览中的 112 / 40 / 24 像素图示用于检查缩小后的轮廓辨识度，不代表已解锁。

- 收藏柜页首仅保留紧凑的解锁统计与细进度条。神话区桌面四栏、中等宽度三栏、手机双栏；保留先前已移除标题与说明的简洁布局。

## 连续性与数据边界

- 小保连胜／连歪仅使用普通限定角色池的已确认结果；大保底跳过不计次。胜利打断连歪，失败打断连胜。未知、冲突、异常和记录缺口均打断连续性，不跨池拼接。
- 连续进度显示已观察到的最长连续机会数或完整间隔数，解锁日期取第一次达标的事件；累计小保命中不要求连续。
- 苦尽星来与双星交辉仅使用已知硬保底的可重复普通机制池，两个完整间隔必须相邻且在同一连续区间。首金下限、异常及特殊未知机制池不算完整有效间隔。
- 群星连奏要求连续 4 个 ≤20 抽间隔，群星俯首要求连续 5 个 ≤10 抽间隔。三金接力／四曜神迹分别要求相邻 2／3 个 1 抽间隔；旧的累计两次 1 抽成就不变。不跨缺口、池或异常。
- 不败欧皇在原五连小保之后增加七连门槛；破晓长歌累计 3 次独立苦尽星来事件，日期取第三次事件；神话破晓神谕提高至 7 次，解锁日期取第七次事件。
- 群星旅伴／群星殿堂按不同角色 ID 去重，分别要求 10／20 位，只计五星；月份按年月去重，不要求连续，不推断登录天数。
- 所有条件仅依据当前保存记录；空档保持样本不足，不能推断缺失的历史事件。
- VERSION 仍为 1，不迁移或写入成就状态；旧存档读取时自动重算新增成就，原记录、此前 41 项条件与整体／角色评分不变。
- 分享中的代表性幸运成就优先考虑新增好运战绩，不把逆风、收藏或数量里程碑放入幸运栏。
