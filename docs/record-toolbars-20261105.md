# 记录页工具栏统一

比较记录改用独立工具栏，上排结果数量，下排搜索、方案状态及重置；不再由通用搜索增强器拆成进阶筛选。空存档仍显示可操作控件和零数量。

喚取历史进一步缩成搜索、筛选按钮及结果数量的一条横列。桌面点击筛选打开原生模态窗口，手机显示底部面板；池别、稀有度、类型和起止日期只在窗口内编辑，按套用才生效。取消或 Escape 不改变已套用条件，窗口内清除先修改草稿；外部清除全部同时清空搜索与筛选。应用后显示可单独移除的条件标签，日期范围合并为一个标签，按钮角标与标签数量一致。日期倒置时提示并保留输入。打开窗口会提交尚在防抖等待中的搜索文字，避免搜索失焦重绘吞掉筛选按钮点击。分页与原始记录判定不变。

成就展示柜将匹配数量、总解锁数量及进度条整合到面板上排，下排保留适用卡池、稀有度、解锁状态和重置。筛选时总解锁进度仍基于完整成就集合；空结果不伪造零解锁。成就条件、图章和评分保持原样。

喚取页工具栏沿用该页既有深蓝灰渐层和主题边框，输入框使用深蓝底，选中五星按钮读取 `--cv-theme`；不套用工作台的绿色面板。成就稀有度和金色解锁进度保持原语义配色。

喚取页首重新整合为单一深蓝灰面板：上排标题、资料管理及导入／更新，下排账号选择与最后更新时间，底部分区导航使用同一图示按钮样式标示当前页。手机操作按钮分成两栏，账号占独立一行，导航保留五个入口并允许文字换行。UID 沿用原遮罩；原账号记忆、导入及路由不变。浏览器检查额外覆盖空账号、五个入口、导入／资料管理、双账号切换及刷新后恢复选择；预览文件后缀为 `header`。

新增文案提供繁简英，手机自动换行。319 项测试通过；`node tests/record-toolbars-browser.cjs` 覆盖 1440／1024／390／320 × 三语 12 组，验证空比较记录、搜索与状态、筛选草稿套用／取消、日期验证、条件标签及清除、搜索后立即开窗、手机底部定位、成就组合筛选、解锁进度及原存档不变。预览位于 `artifacts/record-toolbars-20261105/`。
