# Resonance Register 更新說明

## 這次新增

- **聲骸庫收藏與排序**：可以依名稱、Cost 或資料完整度整理聲骸，並把常用聲骸標記收藏。
- **替換候選比較**：從聲骸庫選擇角色與位置後，Register 會顯示可用候選、主詞條、Cost、套裝、資料完整度與副詞條差異。確認前不會改動角色配置。
- **截圖辨識**：可上傳整張遊戲畫面或右側資訊裁切，先校對辨識結果，再確認加入聲骸庫。
- **完整本機備份**：一次保存角色、聲骸、收藏、比較草稿與本地採用記錄，還原前會先驗證格式。
- **簡略版／詳細版分享圖**：可在角色分析頁選擇分享資訊量，下載清晰 PNG。

## 怎麼使用

在「聲骸庫」中先搜尋或篩選聲骸，按星號即可收藏；排序與收藏篩選會在重新整理後保留。選取聲骸後，在詳情區選擇角色和位置即可開啟替換比較，確認比較結果後才採用。

要使用截圖辨識，按「新增聲骸」並選擇截圖方式。辨識完成後請逐欄檢查名稱、Cost、主詞條與副詞條；只有按下確認加入，資料才會寫入聲骸庫。

## 為什麼要備份

Register 的角色與聲骸資料保存在目前瀏覽器中。清除瀏覽資料、換裝置或瀏覽器重設都可能讓本機資料消失，因此建議在大型整理或換機前下載「完整本機備份」，並在需要時於「資料管理」先驗證再還原。備份不包含登入憑證。
