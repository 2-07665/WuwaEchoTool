# 限定角色展示墙与七阶称号

本版将角色分析入口改为收藏展示：只按取得份数对应 R0～R6，不再展示抽取效率、抽数或额外取得评价。首次取得为 R0，第七份为 R6，第八份以后不升级称号，也不改变第七份的已知日期。

| 链数 | 简体称号 | 繁体称号 | 英文 |
|---|---|---|---|
| R0 | 初遇之契 | 初遇之契 | First encounter |
| R1 | 再响之约 | 再響之約 | Echoing promise |
| R2 | 声息相通 | 聲息相通 | In attunement |
| R3 | 同行知音 | 同行知音 | Kindred companion |
| R4 | 同心协奏 | 同心協奏 | Hearts in harmony |
| R5 | 灵犀交响 | 靈犀交響 | Resonant symphony |
| R6 | 命定同契 | 命定同契 | Bound by destiny |

未取得角色显示“尚未相遇”，不授予 R0 称号。默认只展示已取得角色，可切换全部限定角色后补入缺失记录。卡面只展示立绘、角色名、七阶专属称号章及名称；点击后展示各链称号与达成记录日期。角色范围复用已维护限定活动的角色 ID 与本地身份图鉴，包含已有联动角色，排除常驻与漂泊者；不推测未映射身份。

`ConveneCharacterRating.collection` 合并该角色真实导入取得与独立手动取得，并按用户提供的时间排序。第七份的时间作为本次记录可确认的 R6 日期。这里只描述当前保存记录的达成情况，不声称覆盖账号终身全部历史。

手动来源新增 `history`（补登遗失记录），保留 `coral` 和 `manual`。手动时间允许 `null`；如果该角色存在未知时间，不能排除该记录影响里程碑顺序，因此保留阶段称号但不输出精确达成日期。绝不将补登当天冒充历史满链日期。导入时间仍严格要求原合法时间戳，未放宽导入验证。

补登按一份一项独立保存，仍只允许删除手动 ID。导入 `records`、`spans`、保底、运势与成就不受改变；备份版本仍为 1，手动字段按原规则往返与去重。旧档无需迁移。

分享重新绘制角色纪念卡和展示墙：只绘制立绘、姓名、称号，单角色可附当前阶段已知日期；不包含效率分数、抽数或额外取得次数。展示墙每页 9 位，支持翻页，默认不展示 UID，可选择遮罩 UID。页面和分享读取同一份集合模型。旧效率 API 留作历史规则回归，不再作为角色展示页面的称号来源。

验证：319 项测试通过，包括零份不授称号、首次 R0、七份 R6、超额不改变称号／日期、称号与抽数无关、手动时间缺失、删除权限、原始记录与备份不变。`node tests/convene-collection-browser.cjs` 验证 1440／390／360 三种宽度 × 繁简英、无评分卡面、七阶日期、补登／删除与两类 PNG 分享。合成预览位于 `artifacts/convene-collection-20261104/`。

称号章已按共鸣契印重新设计七个独立中心构图，不复用限定池双星盾；展示墙、七阶历程和纪念卡均恢复图章＋名称。角色展示另有专属七阶边框，`chainFrameArtwork` 同源供页面 SVG、图鉴和分享 Canvas 使用；不修改整体星运或限定池原有图章及边框。

星运图鉴提供整体运势、限定角色运势、限定武器运势及角色称号四类，共 31 阶。每阶并列阶层／名称、现有图章与对应边框预览；整体和两限定池直接调用已有绘制函数，角色预览与展示墙调用同一新增边框函数。图鉴标示当前阶层，角色类可切换已取得角色。三语浏览器测试逐路径比对图鉴与实际图章／边框，确认只增加展示、不改变原设计与规则。图鉴截图位于 `artifacts/convene-atlas-20261104/`。

界面导航已调整为“角色分析墙”：点击角色卡切换到独立角色分析界面，墙面不再和操作区并列显示。详情提供返回墙面、角色切换、立绘／称号、初次取得与 R6 日期，并以共鸣历程、取得时间轴、兑换与手动补入三个页签操作；时间轴保留来源、单次可确认区间、取得统计和五星间隔分布。仅手动补入页可删除手动项。

角色墙与两类分享均将称号章置中放在上方、称号名称在下方；角色名增加深色半透明底牌和细框，与明亮立绘分隔。这些布局调整不改动既有图章／外框路径或称号计算。更新的三语／视口浏览器检查已覆盖进入独立界面、返回墙面、各页签、补登和分享。

图鉴四类顶部统一为当前定位卡：左侧保留原图章，中间突出称号与阶层，右侧独立显示评分／100；角色类保留角色切换，显示七阶位置及当前 R0～R6。手机评分移至独立底行。整体的授予状态、样本门槛、原始分数说明和下一分界移入默认折叠的证据区，计算与判定不变。尚未定阶时不伪造阶层。319 项测试及九组三语／视口图鉴检查通过，包含现有图章与边框路径一致、正文无计算赘述及存档不变。
