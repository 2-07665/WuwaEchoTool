# 角色战报试版与手动取得

此文件为 2026-11-02 历史试版说明。角色页面现已改为七阶链数称号与收藏展示，当前规则见 [角色展示墙](convene-character-collection-20261104.md)。

角色分析改为成果主卡、R0～R6 常显路线、满链后记录及折叠导入时间轴。默认评当前记录已达到的最高阶段，上限 R6；点击阶段切换对应效率。主卡区分喚取和手动份数，记录阶段不宣称账号实际共鸣链或终身持有量。

## 区间与效率

`ConveneCharacterRating.journey` 为页面和三种分享提供同源数据。每份优先使用已有 `targetSpend` 证据；否则从前次同角色取得或最近前置非歪五星边界起算，要求所有间隔完整、同一连续区间、无异常或冲突，目标之间只能出现已确认歪出。首段、缺口、无关 UP 或跨池归属无法确认时保留空值，不将最早可见五星到目标的全部历史视为投入。

每阶显示本次区间、累计区间、中途歪出、效率与日期；累计缺段时不输出完整效率，已知单次与已确认合计仍可查看。满链后的第八次起独立编号，不能改变 R6 成本与评分。最省／最贵／平均跟随选中阶段，仅使用其喚取数据。

试版沿用原线性参考：`100 × (1 − (D − K) / (160K − K))`，限制为 0～100；D 为选中阶段可确认的喚取区间合计，K 为其中实际喚取份数。仅普通限定 UP 角色可评，不代表真实期望、玩家百分位或活动全部投入。当前成果、满链战报、满链后记录分别分享，支持简略／详细、分页和遮罩 UID。

## 手动补入的边界

账号新增可选 `manualAcquisitions`，每项只保存独立 `manual-*` ID、角色资源 ID、取得时间与 `coral`／`manual` 来源。一份一项，可批量补入 1～99 份，总上限 1000 项。该字段独立于 `records`、`spans` 与原保底、成就、出金统计；不会伪造池 0 的导入记录。手动项只在派生战报中使用 `manual` 标识，并在路线上显示来源。

补入影响取得份数、阶段和满链后编号，不参与喚取分数的分子或份数分母。例如实际喚取一份耗 20 抽，加六份兑换后显示记录 R6，但效率仍是 20 抽一份；并非 20 抽七份。全部来自手动补入时显示手动取得，无喚取效率。

战报中的合并时间轴按用户指定取得时间排序；同秒先显示导入取得，再按手动列表顺序排列。手动补入不切断或补全原喚取区间。

新增／删除接口都先验证并复制账号；删除只能命中 `manualAcquisitions` 中的 ID，传入任何导入 ID 都拒绝，原 `records` 和 `spans` 不变。界面只在手动清单提供删除按钮，不提供导入记录的异动入口。修正手动内容可删除后重新补入。

存档版本仍为 1，旧档缺少该字段时按无手动项处理。JSON 备份、恢复、后续导入保留手动清单；合并备份按 ID 去重，同 ID 内容冲突则拒绝。备份恢复可重新带回备份中的手动项。
