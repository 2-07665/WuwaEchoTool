详情默认完整展示主词条和五条副词条；点击“编辑”在同一个模态窗口切换为表单，不再跳转编辑页。表单沿用原词条类别、档位及旧档特殊值保留规则，保存仍通过 Core 的实体 ID、Cost 限制和事务校验。显式保存后刷新列表、引用配置及窗口读数，恢复检视模式；取消或关闭丢弃未保存草稿。收藏和角色上下文变化不会清除正在编辑的草稿，未保存期间暂停装备及角色比较，避免使用旧数据。

悬停反馈作用于整张卡片，包括使用角色及比较按钮区域；移开立即恢复普通边框与底色。关闭详情后取消列表的查看选中状态，不再留下上次查看卡片的亮框。比较选取仅在比较按钮标示，键盘操作保留独立的焦点轮廓。触屏不套用悬停样式，减少动态偏好下禁用过渡。专项浏览器检查覆盖整卡底色／边框、移开复原、关闭及 Escape 后无残留选中态。
