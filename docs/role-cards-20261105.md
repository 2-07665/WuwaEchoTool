# 角色工作台卡牌列表

角色列表默认使用卡牌，保留精简列表切换，并将展示偏好保存在原有导航会话状态中。卡片包含角色图、名称、共鸣链、来源、当前配置、武器资料、五个声骸及原有模型评分。武器资料缺失时明确提示，不虚构装备。比较方案收合在卡片底部，管理菜单复用原有删除确认流程。

五个声骸缩图上方显示配置位置 1～5，下方显示标准化实体 Cost，文字与图片分行，不覆盖图片。空槽保留位置号、费用显示破折号；Cost 缺失同样显示破折号。图片替代文本和悬停提示包含位置、声骸名及 Cost。浏览器检查比对五槽位置和 4／3／3／1／1 费用，顺序来自当前配置，并逐槽核对文字不与图片交叠。

模态标签读取标准化视图模型的 `model.parameters.mode`，沿用现有三语名称，卡牌和精简列表一致。使用当前解析后的模式，包含未设置／失效值的默认回退；不直接展示旧档请求值，不改变评分、模式或原始配置。普通默认模型不额外显示标签。

搜索、来源、状态与排序复用原有逻辑，切换展示不清空筛选、不写核心存档。整张卡牌链接进入对应角色的工作台；导入角色沿用只读页面。键盘可进入角色，管理操作与主链接分离。新版文字提供繁简英。

角色索引控制区整合为紧凑工具栏：上排放结果计数与卡牌／列表切换，下排直接显示搜索、来源、状态、排序及重置，不再重复索引标题或收进进阶筛选。手机自动分行。输入时仅更新结果和计数，保留焦点；通用搜索增强器跳过此独立工具栏，不影响其他页面。专项检查覆盖所有控件可见、1440px 工具栏高度小于 180px、筛选及布局记忆。
